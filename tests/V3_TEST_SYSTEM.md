# Story Analyzer V3: система проверок

Эта система не заменяет legacy-тесты приложения. Она отделяет быстрые смысловые
контракты анализатора от широкой регрессии FrameForge.

## Наборы

| Набор | Команда | Назначение |
| --- | --- | --- |
| Hard gate | `.\Test-Hard.ps1` | Обязательная проверка Forgotten Cities, всех путей анимации, критических V3-контрактов и браузерного интерфейса. |
| Critical | `.\\.venv\\Scripts\\python.exe tests/run_v3_test_system.py critical` | Быстрая проверка обязательных смысловых контрактов после каждой правки V3. |
| Regression | `.\\.venv\\Scripts\\python.exe tests/run_v3_test_system.py regression` | Все тесты V3 после завершения небольшого изменения. |
| Full application | `.\Test-Full.ps1` | Редкий полный прогон перед релизом или при поиске широкой регрессии. |

По умолчанию используется `Hard gate`. Полный набор не запускается при обычной
установке и после локальных правок.

## Правило качества

Критический тест проверяет точный смысловой контракт: сущность, её присутствие
в конкретном событии, субъект факта, предикат, значение и отсутствие лишнего
результата. Тест, который проверяет только число объектов, наличие поля или
отсутствие исключения, не является критерием качества анализа.

## Запрещённые изменения тестов

Нельзя ослаблять assertion, менять исходный контрпример на более удобный,
добавлять исключение для конкретного имени или превращать ошибку в warning ради
зелёного прогона. Если тест не проходит, исправляется production-код или
добавляется прозрачная диагностика, которая доказывает невозможность решения.

## Статус на момент создания

`critical` намеренно фиксирует известные семантические дефекты текущего V3.
Пока он красный, переход к Coreference Resolver V3 запрещён.
