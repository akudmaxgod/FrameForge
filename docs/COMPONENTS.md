# Зависимости и отдельные компоненты

## Основная программа

Windows portable содержит Python 3.12 и основные библиотеки. `requirements.txt` закрепляет
полное дерево основных зависимостей из проверенного окружения. `requirements-build.txt`
задаёт PyInstaller. Исходники устанавливаются через `Install.ps1` в новую `.venv`.
Системный Python и окружение LIVE не обновляются.

Включены Pillow, PyAV, NumPy, OpenCV, Natasha/морфология и транспорт DeepSeek.
Для нового пользователя по умолчанию выбран Flow; отсутствующие локальные ComfyUI-модели
не блокируют запуск интерфейса.

## Qwen3-VL: анализ материалов

Требуются отдельно:

```text
backends/llama-cuda/llama-server.exe
backends/llama-cuda/*.dll
backends/models/qwen3-vl/Qwen3VL-4B-Instruct-Q4_K_M.gguf
backends/models/qwen3-vl/mmproj-Qwen3VL-4B-Instruct-F16.gguf
```

Официальные источники: [llama.cpp](https://github.com/ggml-org/llama.cpp/releases),
[модель Qwen GGUF](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF).
Нужна CUDA-сборка, совместимая с GPU и драйвером пользователя. Все DLL берутся комплектом
одного выпуска, а не смешиваются между версиями.

`components-lock.json` содержит размеры/SHA256 **проверенного локального набора**.
Сами бинарники и модели не вложены в Windows/source ZIP и Git. Текущая версия скрипта
устанавливает именно этот набор из отдельной доступной пользователю папки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\InstallQwen.ps1 -FromInstallation "D:\KnownGoodFrameForge"
```

При совпадении уже существующих файлов повторное копирование не выполняется; другая версия
не перезаписывается автоматически. Изменения компонентов требуют нового проверенного lock.
Для новой установки с нуля загрузчик фиксированного upstream-выпуска ещё не реализован:
комплект должен подготовить сопровождающий либо пользователь берёт файлы upstream и проверяет
совместимость. Не выдавайте базовый ZIP за установку Qwen одной кнопкой.

Пик VRAM и скорость зависят от видеокарты, драйвера, разрешения и других программ.
Измерения RTX 3070 не являются гарантией отсутствия OOM на чужом ПК.

## Распознавание речи и смысловая подгонка

1. Установите Python 3.12 x64 с https://www.python.org/downloads/windows/.
2. Выполните `InstallVoice.ps1`: создаст отдельную `backends/voice-venv`, установит
   закреплённые зависимости и загрузит Whisper turbo. Это распознавание загруженной озвучки,
   не генератор голоса.
3. При необходимости выполните `InstallSemanticFit.ps1`: установит ONNX/tokenizer и модель
   MiniLM по фиксированной ревизии из `scripts/install_semantic_model.py`.
4. Перезапустите FrameForge и проверьте короткое аудио.

При обновлении скрипты используют общий `components_path` из профиля. Модели и виртуальные
среды не копируются из чужого ПК как переносимая Python-установка.

## Что не обновляется автоматически

ComfyUI, YOLO, InsightFace и их веса не входят в базовый EXE. Файлы старых модулей сохранены
в исходниках для совместимости, но эти backend-профили требуют отдельной сборки/проверки.
Не устанавливайте `requirements-face.txt` в расчёте добавить пакет внутрь уже собранного EXE.

Пакеты и модели имеют отдельные лицензии: смотрите `THIRD_PARTY_NOTICES.md` и файлы
upstream. Сохранённые лицензии библиотек находятся в `docs/third-party`.
