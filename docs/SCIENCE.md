# Научпоп и CUDA

Для всех новых научпоп-планов применяется общая монтажная политика. Она учитывает функцию сцены, длительность, доступные пояснения, схемы и соседние сцены. Варианты: раскрытие со смещением, поэтапные пояснения без смещения, спокойный крупный план, общий вид с деталью, общий вид с панорамой деталей. Панорамы распределяются между другими постановками и не повторяются в каждой сцене. Одиночная иллюстрация допустима при обоснованной необходимости. Ручной выбор постановки сохраняется.

Автоматическое распределение работает при подготовке, повторном использовании и импорте научпоп-планов. Сохранённые старые видео не изменяются автоматически.

Тексты и маски подготавливаются один раз. Изображения, раскрытия и смешивание собираются на CUDA; кодирование использует NVENC. Передача YUV-кадра кодировщику остаётся, это не zero-copy pipeline. Дискретная NVIDIA GPU с совместимым драйвером необходима для новых GPU-постановок; скрытого тяжёлого CPU fallback нет.

Windows-сборка включает CuPy, CUDA Runtime и NVRTC для локального композитора. ASR, нейросетевые детекторы и дополнительные модели устанавливаются отдельно. Настройте дополнительные компоненты по docs/COMPONENTS.md.

Для подходящей сцены планировщик создаёт 2–4 шага: дословная уникальная цитата из текста, короткий заголовок, пояснение и название области. До озвучки время оценивается по положению цитаты; подгонка к голосу заменяет оценки речевыми отметками. Заголовок сцены виден с первого кадра.

В панораме общий вид и неподвижная рамка крупного плана показывают одну сцену с единым временем. Камера плавно проходит промежуточные области. Проверенные подвижные части и пути условных импульсов хранятся в координатах исходника. Перемотка восстанавливает состояние по абсолютному времени.

Области определяет установленная локальная Qwen3-VL: два независимых прохода должны согласиться. Анализ выполняется в фоне после загрузки иллюстрации. При сборке всего ролика программа дожидается анализа перед синхронизацией и подгонкой. Если модель отсутствует или область не подтверждена, остаётся общая иллюстрация с пояснениями. Рисовать области и выставлять время вручную не требуется. Новые платные генерации для этой проверки не запускаются. Компоненты модели устанавливаются отдельно; настройка `science_auto_grounding: false` отключает фоновый анализ.

Сохранённые видео и ручные постановки автоматически не заменяются. Чтобы применить новую политику к прежнему проекту, повторно подготовьте научный план и обновите источники монтажа.

Монтаж экспортируется в HD/Full HD с 24, 30 или 60 кадрами/с. Частота не меняет скорость камеры и эффектов. Готовые части длинной сборки сохраняются до успешного завершения; после сбоя доступна кнопка «Продолжить сборку», пока версия монтажа совпадает. Изменённый монтаж требует нового экспорта. Проверка свободного места и CUDA/NVENC выполняется перед приёмом задачи. Штатная остановка программы отклоняется, пока экспорт в очереди или выполняется.

Проверка пяти вариантов и NVENC без пользовательских проектов:

```powershell
.\FrameForge.exe --verify-gpu --output .\gpu-check
```

Команда создаёт только тестовые изображения, пять двухсекундных MP4 и verification.json в указанной папке. Проверка панорамы включает общие подвижные слои и путь импульсов. Она не обращается к платным моделям.
