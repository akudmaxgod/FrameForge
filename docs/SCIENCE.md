# Научпоп и CUDA

Для всех новых научпоп-планов применяется общая монтажная политика. Она учитывает функцию сцены, длительность, доступные пояснения, схемы и соседние сцены. Варианты: раскрытие со смещением, поэтапные пояснения без смещения, спокойный крупный план, общий вид с деталью. Одиночная иллюстрация допустима при обоснованной необходимости. Ручной выбор постановки сохраняется.

Автоматическое распределение работает при подготовке, повторном использовании и импорте научпоп-планов. Сохранённые старые видео не изменяются автоматически.

Тексты и маски подготавливаются один раз. Изображения, раскрытия и смешивание собираются на CUDA; кодирование использует NVENC. Передача YUV-кадра кодировщику остаётся, это не zero-copy pipeline. Дискретная NVIDIA GPU с совместимым драйвером необходима для новых GPU-постановок; скрытого тяжёлого CPU fallback нет.

Windows-сборка включает CuPy, CUDA Runtime и NVRTC для локального композитора. ASR, нейросетевые детекторы и дополнительные модели устанавливаются отдельно. Настройте дополнительные компоненты по docs/COMPONENTS.md.

Проверка четырёх вариантов и NVENC без пользовательских проектов:

```powershell
.\FrameForge.exe --verify-gpu --output .\gpu-check
```

Команда создаёт только тестовые изображения, четыре двухсекундных MP4 и verification.json в указанной папке. Она не обращается к платным моделям.
