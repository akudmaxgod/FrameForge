# Задание агенту: установить FrameForge и компоненты на другом Windows-ПК

Версия инструкции: 0.2.0rc3 / 2026-11-05. Выполнять на компьютере получателя.

## Готовая задача для передачи агенту

> Установи FrameForge из приватного репозитория https://github.com/akudmaxgod/FrameForge,
> выпуск v0.2.0rc3. Прочитай эту инструкцию, README.md, docs/UPDATE.md,
> docs/COMPONENTS.md и docs/FLOW.md. Установи программу и компоненты для генерации
> через Flow, анализа картинок/видео Qwen3-VL, распознавания озвучки Whisper turbo
> и смысловой подгонки MiniLM. Определи оборудование и пути, сохрани существующие
> проекты и настройки, проверь реальные функции. Обычное открытие интерфейса
> не считай завершённой установкой. В конце оставь отчёт по каждому компоненту:
> установлен и проверен / не требуется / заблокирован с конкретной причиной.
> Ключи и вход в аккаунты выполняет владелец; секреты не выводи в чат и логи.

## 1. Осмотр компьютера и доступ

1. Определи Windows x64, RAM, доступный диск, модель GPU, объём VRAM и драйвер.
   Для NVIDIA используй `nvidia-smi`, если команда доступна. Не переноси результаты
   RTX 3070 разработчика на чужой компьютер как гарантию скорости или запаса VRAM.
2. Найди существующие установки FrameForge и их `.frameforge-profile.json`.
   Зафиксируй пути программы, `data` и компонентов. Не удаляй старые каталоги.
3. Предложи постоянную папку, например `D:\FrameForge\0.2.0rc3`, и свободное место
   под приложение, модели, загружаемые архивы и резервную копию существующих данных.
   Требуемое место вычисляй по размерам загрузок; не скачивай все варианты моделей.
4. Репозиторий приватный: получатель должен быть приглашён владельцем в Collaborators
   и войти со своего аккаунта. Не используй и не запрашивай чужой токен.

## 2. Программа или обновление

1. Скачай `FrameForge-0.2.0rc3-windows-x64.zip` и `SHA256SUMS.txt` из
   [GitHub Releases](https://github.com/akudmaxgod/FrameForge/releases/tag/v0.2.0rc3).
2. Сравни SHA256 архива с опубликованной суммой. Распакуй **всю папку FrameForge**,
   включая `_internal`, рядом со старой версией. Один EXE отдельно не переносится.
3. Из папки программы выполни:

```powershell
.\FrameForge.exe --verify-release
```

4. Для обновления дождись окончания задач, сохрани монтаж и штатно останови старую
   программу. Запусти в новой папке:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Prepare-Update.ps1 -PreviousInstallation "D:\FrameForge-old"
```

   Если данные вынесены отдельно — добавь `-PreviousData "D:\FrameForgeData"`.
   Проверь созданную резервную копию и пути профиля. Не копируй чужую базу или секреты.
5. Запусти `Start.cmd`. Порт 8765 должен принадлежать этой установке. При занятом порте
   выясни владельца процесса, не завершай произвольные программы по номеру порта.
6. Проверь `/api/editorial-capabilities`: `release_version` должен быть `0.2.0rc3`.
   Portable содержит основной Python и библиотеки; `pip install` в `_internal` не нужен.

## 3. Отдельный Python для дополнительных компонентов

1. Для Whisper/MiniLM нужен установленный Python 3.12 x64. Проверь `py -3.12 --version`.
   Если его нет, установи с [python.org](https://www.python.org/downloads/windows/).
2. Используй `components_path` из `.frameforge-profile.json`, если он есть; иначе
   компоненты размещаются в папке программы. Не создавай второй случайный каталог моделей.
3. Не обновляй глобальные библиотеки и не выполняй `pip install -U` для всех пакетов.
   Используй закреплённые requirements и отдельные виртуальные среды.

## 4. Распознавание речи Whisper turbo

Из папки FrameForge:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\InstallVoice.ps1
```

Для отдельного каталога добавь `-ComponentsPath "D:\FrameForgeComponents"`, согласовав
этот же путь в профиле программы. Скрипт создаёт `backends\voice-venv` и загружает
модель в `models\voice\turbo`. Текущий репозиторий модели:
[dropbox-dash/faster-whisper-large-v3-turbo](https://huggingface.co/dropbox-dash/faster-whisper-large-v3-turbo).
Прежний адрес mobiuslabsgmbh в InstallVoice.ps1 перенаправляется туда.

Проверить:

- `backends\voice-venv\Scripts\python.exe -m pip check`;
- `model.bin`, `config.json`, `tokenizer.json` в `models\voice\turbo`;
- после перезапуска `/api/voice/capability` возвращает `ready: true`;
- короткое аудио действительно распознаётся и получает временные границы.

В этой версии `voice_asr.py` использует **CPU/int8**. Для этого маршрута cuDNN и
полный CUDA Toolkit устанавливать не требуется. Это распознавание готовой озвучки,
не синтез голоса. GPU-Whisper — отдельная настройка и проверка, не обещание этого пакета.

## 5. Смысловая подгонка MiniLM

После InstallVoice:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\InstallSemanticFit.ps1
```

Скрипт скачивает закреплённую ревизию `paraphrase-multilingual-MiniLM-L12-v2`
в `models\semantic-mini`, включая ONNX и tokenizer, и записывает `MODEL.json` с SHA256.
Проверь файлы, `pip check` отдельного voice-venv и реальную короткую подгонку монтажа.
Не заменяй модель на более крупную без изменения кода и повторных проверок.

## 6. Qwen3-VL: зрительный анализ фото/видео

Приложению нужны следующие пути **от components_path**:

```text
backends/llama-cuda/llama-server.exe
backends/llama-cuda/*.dll
backends/models/qwen3-vl/Qwen3VL-4B-Instruct-Q4_K_M.gguf
backends/models/qwen3-vl/mmproj-Qwen3VL-4B-Instruct-F16.gguf
```

### Вариант A: есть проверенный комплект от владельца

Если предоставлена папка с файлами, соответствующими `components-lock.json`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\InstallQwen.ps1 -FromInstallation "D:\FrameForge-components-kit"
```

При вынесенных компонентах добавь `-ComponentsPath`. Скрипт проверяет каждую сумму
до копирования. Комплект не содержит пользовательских data, `.env` и ключей.
Сам комплект Qwen в базовый GitHub ZIP не включён.

### Вариант B: чистый ПК, комплекта нет

`InstallQwen.ps1` **не скачивает** файлы из интернета: это копировщик проверенного
набора. В этом случае агент устанавливает компоненты из официальных источников:

1. Открой [llama.cpp Releases](https://github.com/ggml-org/llama.cpp/releases).
   Выбери Windows x64 CUDA 12 runtime, совместимый с NVIDIA GPU/драйвером и поддержкой
   Qwen3-VL/mmproj. Зафиксируй тег выпуска и URL; не используй незафиксированный latest
   в итоговом отчёте. Возьми все требуемые DLL этого выпуска, включая отдельный CUDA
   runtime-архив, если он указан в его составе. Не смешивай DLL разных выпусков.
2. Распакуй бинарники в `backends\llama-cuda` так, чтобы `llama-server.exe` был
   непосредственно в этой папке. Проверь `llama-server.exe --version` и `--help`.
   Приложение использует `--mmproj`, `-ngl 99`, `-fa on`, контекст 4096 и localhost.
3. Из [официального GGUF-репозитория Qwen](https://huggingface.co/Qwen/Qwen3-VL-4B-Instruct-GGUF/tree/main)
   скачай **только два файла** из списка выше: Q4_K_M и проектор F16. Зафиксируй commit
   репозитория и загрузку с этой ревизии. Не скачивай основную модель F16/Q8 или все
   квантизации; проектор должен соответствовать Qwen3-VL-4B, не 2B/8B/Qwen2.
4. Проверь размер файлов, целостность загрузки и доступные upstream SHA256/LFS-хеши.
   Запиши локальные SHA256, происхождение и версии в отдельный отчёт установки.
   Если свежие бинарники отличаются от `components-lock.json`, это **другой набор**:
   не редактируй эталонный lock, чтобы скрыть несовпадение, и не объявляй его заранее
   проверенным. Совместимость подтверждается следующими реальными тестами.
5. Перезапусти FrameForge и проанализируй одну фотографию через медиатеку. Сервер
   модели запускает само приложение на `127.0.0.1:11438`. Не запускай параллельный
   сервер на том же порту и не открывай его наружу.
6. Проверь завершённый JSON-анализ, затем короткое видео с ключевыми кадрами, повторный
   анализ из кэша и подбор по одной фразе. При нехватке VRAM выясни фоновые потребители
   и совместимость GPU; не отключай проверки ошибок и не обещай отсутствие OOM.

Без NVIDIA/подходящего драйвера этот CUDA-маршрут не считается установленным. CPU/Vulkan
требуют отдельной адаптации запуска и проверки; нельзя просто подложить другой EXE
и заявить полную GPU-готовность. Сам монтаж и ручной импорт работают без Qwen.

## 7. Генерация изображений и анимаций через Flow

1. В браузере владельца установить [Tampermonkey](https://www.tampermonkey.net/).
2. При работающем FrameForge открыть
   `http://127.0.0.1:8765/frameforge-flow-v1.user.js` и установить/обновить **существующий**
   FrameForge Flow Bridge (new) до **0.1.89**. Не оставлять две включённые копии.
3. Владелец входит в свой Flow. Нужен доступный ему инструмент Bridge с адаптером
   из `integrations/flow-v1/FrameForgeBridge.tsx` в среде, где доступен flow-sdk.
   Сам файл TSX не является развёрнутым инструментом; получить доступ или создать
   его по docs/FLOW.md. Не копировать чужую закрытую ссылку как универсальную.
4. Сохранить собственную ссылку в настройках FrameForge → Google Flow. Открыть
   инструмент, оставить вкладку, проверить связь и привязку текущего проекта.
5. При наличии разрешённой квоты проверить один портрет, закрепить его вручную,
   затем один кадр; при необходимости одну выбранную анимацию. Не запускать
   сотни платных запросов как тест установки. Политика доступа/квоты определяется Flow.
6. Сохранённое состояние userscript и неизвестные исходы запросов не сбрасывать:
   перед повтором сначала искать уже созданный результат.

## 8. Ключи, поиск материалов и озвучка

- DeepSeek: собственный ключ владельца для разбора сценария. Вводить через штатные
  настройки/конфигурацию, не в код, Git, скриншоты или отчёт. Не объявлять этот API бесплатным.
- Pixabay: свой API key в настройках, проверка связи, один поиск фото и один видео,
  повторный поиск из кэша. Не запускать массовую выгрузку каталога.
- Commons/Openverse и браузерный поиск проверить отдельно. Отсутствие результата
  конкретного запроса — не доказательство поломки программы.
- SearXNG — дополнительный источник. Docker/WSL не нужны для базовой работы FrameForge,
  Commons, Openverse и ручного поиска; не устанавливать их автоматически ради этого пункта.
- Генератор голоса в этот комплект не входит: для теста импортировать готовое аудио.
  Whisper не заменяет TTS. Компоненты ComfyUI/YOLO/InsightFace — отдельный локальный
  профиль, не обязательная зависимость маршрута Flow. Установка pip-пакета не встраивает
  его в замороженный EXE. Если владелец требует именно этот профиль, установить отдельный
  исходный runtime по его документации, моделям и лицензиям и проверить отдельно.

## 9. Приёмка: обязательно проверить работу, а не только файлы

Создай отдельный тестовый проект из 3–5 коротких фраз; существующие проекты не изменять.

1. Открытие UI, настройки и сохранение собственного Bridge URL; отсутствие JS-ошибок.
2. Разбор короткого сценария, правильные участники; выбранная камера «Панорама».
3. Портрет → ручная проверка/закрепление → кадр Flow, если подключён аккаунт/квота.
4. Импорт локальных фото и видео непосредственно в монтаж **без обязательного Qwen**.
5. Qwen отдельно: анализ фото и видео, завершённый результат без скрытого fallback.
6. Whisper: реальное распознавание короткой речи; MiniLM: реальная подгонка.
7. Наложение футажа поверх генерации → скрыть/удалить → исходный кадр возвращается,
   тайминг и озвучка сохраняются. Заглушить исходный звук футажей.
8. Сохранить и экспортировать MP4, открыть его, проверить длительность, картинку и звук.
9. Перезапуск, сохранность тестового проекта, штатная остановка. При обновлении сверить
   прежнее число сцен и доступность материалов без их перегенерации.

Итоговый INSTALLATION_REPORT.md должен содержать версию приложения/Bridge, оборудование,
пути, реальные версии и SHA256 компонентов, таблицу проверок и ограничения. Не писать
«всё установлено», если остались недоступный Bridge, нескачанные веса, сбой анализа,
нераспознанное аудио или непроверенный экспорт. Секреты и тексты личных проектов исключить.

Справочные файлы: [COMPONENTS.md](COMPONENTS.md), [FLOW.md](FLOW.md), [UPDATE.md](UPDATE.md),
[README](../README.md). Инструкция не является автоматическим установщиком моделей:
её должен выполнить агент на целевом ПК и подтвердить фактические результаты.
