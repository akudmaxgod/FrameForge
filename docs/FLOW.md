# Google Flow и FrameForge Bridge

Для Flow нужны три части:

1. Запущенный FrameForge на `http://127.0.0.1:8765`.
2. Расширение Tampermonkey и userscript **FrameForge Flow Bridge (new)** 0.1.93.
3. Доступный вашему Google-аккаунту инструмент Flow с адаптером FrameForge и поддержкой `flow-sdk`.

## Подключение

1. Установите Tampermonkey с https://www.tampermonkey.net в браузере, где используете Flow.
2. Запустите FrameForge. Откройте `http://127.0.0.1:8765/frameforge-flow-v1.user.js`
   и подтвердите установку в Tampermonkey. Если браузер требует разрешение userscripts,
   включите его в настройках расширения по инструкции Tampermonkey для своего браузера.
3. Войдите в свой аккаунт на https://flow.google.com.
4. Получите у владельца проекта доступную ссылку на **инструмент FrameForge Bridge**
   либо создайте инструмент в среде Flow из `integrations/flow-v1/FrameForgeBridge.tsx`.
   Это React-компонент среды Flow; обычный браузер/Node не заменяет `flow-sdk`.
5. В FrameForge откройте настройки → Google Flow → «Ссылка на ваш FrameForge Bridge».
   Вставьте ссылку на инструмент и сохраните.
6. Откройте инструмент кнопкой «Открыть FrameForge Bridge», оставьте вкладку открытой.
7. Нажмите «Проверить мост». Проверьте, что привязан именно текущий проект FrameForge.
8. Сначала сгенерируйте один тестовый кадр. Затем проверяйте пакетную генерацию.

Поставка включает исходный адаптер, но не развёрнутый общий инструмент и не доступ
к чужому аккаунту Flow. До выдачи релиза владелец должен подготовить доступную тестировщикам
ссылку и проверить SDK в их аккаунте. Это обязательный пункт пилота.

## Обновление

Локальная ссылка userscript остаётся прежней, поэтому приватный raw URL GitHub не нужен.
Обновляйте существующий script, а не создавайте копию. Состояние `ff-flow-v1-state`, очередь
и неизвестные исходы запросов сохраняйте. Перезапуск приложения сам по себе не означает,
что запрос Flow не выполнился.

Версия канала: `frameforge.bridge.v1`; адаптер сообщает `protocolVersion: 2`.
Адрес 8765 закреплён в userscript. Другой порт требует отдельного согласованного профиля
userscript; тестовую копию не подключайте к рабочему мосту.
