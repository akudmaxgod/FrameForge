Перед публикацией упаковка повторно проверяет отсутствие данных/очевидных ключей и формирует
SHA256 для файлов и архивов. Это автоматическая проверка типовых утечек, не доказательство
абсолютного отсутствия любого секрета. В снимок изначально включены только код и ресурсы.

Ещё нужны: запуск на другом Windows-ПК без Python; Flow/адаптер на отдельном аккаунте;
полный пользовательский проект с Qwen и распознаванием речи на целевой машине;
проверка комплекта лицензий именно для внешнего распространения. Эти проверки не заявлены
выполненными. Выпуск имеет статус кандидата закрытого тестирования.
