# FrameForge — кандидат выпуска 0.2.0rc4

Локальная программа для подготовки сцен, генерации через Google Flow, монтажа,
анализа своих материалов локальной Qwen3-VL и поиска фото/видео через Pixabay.
Интерфейс открывается в браузере по адресу `http://127.0.0.1:8765`.

## Первый запуск Windows x64

1. Скачайте **FrameForge-0.2.0rc4-windows-x64.zip** из Releases приватного репозитория.
   Автоматический GitHub `Source code (zip)` — исходники, а не готовая программа.
2. Распакуйте архив целиком в доступную для записи папку. Сохраните `_internal` рядом с EXE.
3. Запустите `Start.cmd`. Устанавливать Python для этой сборки не требуется.
4. Настройте свой ключ DeepSeek в интерфейсе, если нужен разбор сценария.
5. Для генерации подключите Tampermonkey и свой доступный инструмент Flow:
   [подключение Flow](docs/FLOW.md). Сам EXE не заменяет этот инструмент.
6. Для поиска стоков укажите свой ключ Pixabay в настройках. Импортированные материалы
   можно анализировать после установки Qwen: [компоненты](docs/COMPONENTS.md).

## Обновление существующей установки

Сохраните новую программу в отдельную папку, остановите старую после завершения задач
и выполните в PowerShell из новой папки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Prepare-Update.ps1 -PreviousInstallation "D:\FrameForge-old"
```

Скрипт проверит файлы выпуска, сделает и проверит полную резервную копию старого `data`
и подключит эту папку данных к новой версии. Он не заменяет старую программу и не запускает
генерацию. Затем откройте `Start.cmd` **в новой папке**.

Подробности, включая откат: [UPDATE.md](docs/UPDATE.md).

## Что входит

| Компонент | В поставке |
|---|---|
| FrameForge, монтаж, импорт фото/видео, Pixabay | Да |
| Python и основные библиотеки | Да, в Windows portable ZIP |
| Userscript Flow 0.1.93 и исходник адаптера | Да; устанавливаются отдельно |
| Аккаунт/инструмент/подписка Flow | Пользователь подключает свои |
| Ключи DeepSeek/Pixabay | Пользователь указывает свои |
| Qwen, CUDA runtime и веса | Отдельно, примерно 4.5 ГБ в проверенном наборе |
| Распознавание речи и его модель | Отдельно через InstallVoice.ps1, нужен Python 3.12 |
| ComfyUI, InsightFace/YOLO и их модели | Не включены в базовый EXE |

## Установка с помощью агента

Передайте агенту [пошаговое задание установки всех компонентов](docs/AGENT_INSTALL_RU.md).
Оно охватывает обновление программы, Qwen3-VL, Whisper, MiniLM, подключение Flow и
проверку реального экспорта. Модели устанавливаются отдельно; инструкция включает
маршрут загрузки с официальных источников для чистого компьютера.

## Разработка

Для исходников нужен Python 3.12 x64. Выполните `Install.ps1`, затем `Start.cmd`.
Для сборки: `Install.ps1 -Build`, затем `Build.ps1`.

Основные зависимости закреплены в `requirements.txt` со всеми транзитивными зависимостями.
Они установлены и проверены в отдельной чистой среде. Переход на новые версии библиотек
делается отдельным выпуском после проверок, а не командой обновления на компьютерах пользователей.

Документы: [публикация приватного репозитория](docs/PUBLISH_PRIVATE_GITHUB.md),
[план внедрения](docs/ROLLOUT.md), [проверки](docs/VALIDATION.md),
[сторонние компоненты](THIRD_PARTY_NOTICES.md).

Кандидат требует проверки Flow на отдельном аккаунте и запуска на другом Windows-ПК
перед массовой выдачей пользователям. Приватный GitHub не заменяет условия использования
внешних сервисов и лицензии установленных моделей.
