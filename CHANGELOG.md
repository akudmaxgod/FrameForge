# Изменения

## 0.2.0rc1 — кандидат закрытого теста, 2026-11-02

- Очищенный снимок текущего LIVE: исходные сцены, монтаж, фото/видео, Pixabay, анализ Qwen.
- Футаж хранится поверх исходного сгенерированного сегмента; можно скрыть/удалить его
  и вернуть кадр, сохраняя длительность и озвучку.
- Подбор ориентирован на целый сегмент озвучки, а не множество коротких перебивок.
- Отдельные переносимые пути данных/компонентов, запуск без путей разработчика.
- Обновление отдельной папкой с проверяемой резервной копией, без замены рабочего LIVE.
- Явный набор закреплённых зависимостей, новая сборка Windows onedir и контрольные суммы.
- Настраиваемая ссылка на инструмент Flow вместо личного проекта разработчика.
- Userscript 0.1.82: строгая проверка имени хоста Flow; прежнее хранилище состояния сохранено.
- Остановка больше не уничтожает процессы по общим портам локальных backend-сервисов.
- В runtime включён недостающий публичный PEM-файл Python; проверка выпуска проверяет TLS-контекст.

Ограничения: закрытый пилот; нет фонового обновления private GitHub, общего опубликованного
инструмента Flow, моделей Qwen/Whisper в базовом ZIP и подписи Windows EXE.
