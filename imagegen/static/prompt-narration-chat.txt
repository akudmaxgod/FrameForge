Подготовь готовые визуальные промпты по нашему сценарию для импорта в FrameForge.

Верни файл JSON: один массив объектов, в каждом ровно два текстовых поля:
{"narration": "точный фрагмент моего сценария", "prompt": "визуальный промпт для соответствующего кадра"}.

Требования:
1. Сохрани порядок сценария. Покрой весь произносимый текст без пропусков и повторов. В narration копируй текст сценария дословно, не пересказывай и не исправляй его.
2. Один объект — один кадр, ориентировочно на 5 секунд чтения. Не разрывай фразу посередине только ради пяти секунд: окончательное время задаст реальная озвучка.
3. В prompt опиши видимые объекты, действие и композицию, связанные с narration. Кинематографический стиль, формат 16:9. Чередуй общий, средний, крупный и предметный планы; для сложных объяснений выбирай понятные предметные иллюстрации.
4. Не добавляй произносимый текст, титры, команды монтажа или временные метки внутрь prompt. Narration хранится отдельно.
5. Каждый prompt — не более 1950 символов; narration — не более 4000. Файл должен быть корректным JSON в UTF-8, без Markdown-ограждений и комментариев.

Пример:
[
  {"narration": "На берегу стоял старый маяк.", "prompt": "Общий план старого каменного маяка на морском берегу на рассвете. Кинематографический реализм, 16:9."},
  {"narration": "В комнате смотрителя лежал медный компас.", "prompt": "Крупный план медного компаса на деревянном столе, боковой свет из окна маяка. Кинематографический реализм, 16:9."}
]
